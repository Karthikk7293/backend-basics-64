# backend basics 64

Express and MongoDB learning project with user authentication, product and cart routes, and e-commerce data models.

[Website](https://backend-basics-64.vercel.app)

## Project scope

This is a backend learning exercise. Configure the MongoDB connection and authentication settings before using the user, product, and cart routes.

## Run locally

Install Node.js and the package manager used below. Run each command block from the repository root; separate frontend/backend processes use separate terminals.

Root application:

```sh
npm install
npm run dev
```
